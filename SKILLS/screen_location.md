# Skill: ค้นหาจอและสถานที่ใกล้เคียงตามพิกัด

## เป้าหมาย

ช่วยค้นหาจอ Screen สาขา หรือห้างสรรพสินค้าที่อยู่ใกล้เคียงจุดอ้างอิงที่ผู้ใช้สอบถาม โดยใช้กระบวนการ Tool Chaining ระหว่างการดึงข้อมูล Screen และการคำนวณระยะทางทางภูมิศาสตร์

## ใช้เมื่อ

- ผู้ใช้ถามว่ามีจอ ห้าง หรือสาขาใดอยู่ใกล้กับสถานที่เป้าหมาย เช่น "มีห้างไหนใกล้ Central World บ้าง"
- ผู้ใช้ต้องการหารายชื่อจอที่อยู่ในรัศมีที่กำหนดรอบพิกัดหรือสถานที่อ้างอิง

## ขั้นตอนการทำงาน (Tool Chaining)

1. **ระบุพิกัดอ้างอิง (Origin):**
   - หากผู้ใช้ระบุสถานที่สำคัญ (เช่น Central World, Siam Paragon) ให้กำหนดพิกัด `latitude` และ `longitude` อ้างอิงของสถานที่นั้น
   - หากเป็นสาขาที่มีในระบบ ให้ใช้ `targetr_query` เพื่อค้นหาพิกัดของสาขานั้นก่อน

2. **ดึงข้อมูล Screen ที่มีพิกัด:**
   - เรียก MCP tool `targetr_query` โดยเลือกเฉพาะ fields ที่จำเป็น:
     ```json
     {
       "entity": "screen",
       "operation": "select",
       "fields": ["label", "storeLocation", "latitude", "longitude"],
       "limit": 100
     }
     ```
   - ไม่ดึง fields ที่ไม่เกี่ยวข้อง และไม่ขอ raw data

3. **คำนวณระยะทางและคัดกรอง (Geo Calculation):**
   - นำพิกัด origin และรายการจอที่ได้จากขั้นตอนที่ 2 มาส่งต่อให้ MCP tool `geo_distance`:
     ```json
     {
       "origin": { "latitude": 13.7469, "longitude": 100.5398 },
       "destinations": [ ...รายการจอที่มีพิกัด... ],
       "max_distance_km": 3.0,
       "limit": 5
     }
     ```
   - ให้ tool ทำหน้าที่คำนวณระยะทาง กรองตามรัศมี และเรียงลำดับจากใกล้ไปไกล

4. **สรุปและตอบผู้ใช้:**
   - ตอบเฉพาะชื่อสถานที่/ห้าง/สาขา และระยะทางโดยประมาณ (เช่น "ห่างออกไปประมาณ 400 เมตร")
   - ระบุเงื่อนไขให้ผู้ใช้ทราบว่า เป็นข้อมูลเฉพาะสถานที่ที่มีการติดตั้งจอในระบบ Target-R เท่านั้น
   - **ห้าม** แสดงพิกัดตัวเลขละติจูด/ลองจิจูดแบบละเอียด หรือ Screen ID ต่อผู้ใช้ เว้นแต่ผู้ใช้จะร้องขอโดยตรง
