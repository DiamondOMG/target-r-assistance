# พิกัด GPS ที่ยังไม่ระบุอุปกรณ์

ต้นฉบับไม่ระบุชื่อเครื่องหรือสถานที่ จึงยังไม่ผูกกับอุปกรณ์ใด พบค่าชุดเดียวกันซ้ำสองครั้ง เก็บไว้หนึ่งชุด

```text
gpsLatitude: 13.86536
gpsLongitude: 100.49693
```
