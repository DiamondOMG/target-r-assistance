# คู่มือเปิด Debug Mode และเชื่อมต่อ ADB เข้ากล่อง Playbox

คู่มือสำหรับผู้ใช้งาน / ทีม Operation ในการเตรียมกล่อง **Playbox (Android TV Box)** เพื่อเปิดโหมดดีบัก (Debug Mode) และให้ AI เชื่อมต่อผ่าน **ADB (Android Debug Bridge)** เข้าไปตรวจสอบค่า ปรับตั้งค่า หรือดำเนินการต่าง ๆ ผ่านเครือข่าย LAN/Wi-Fi

---

## ขั้นตอนที่ผู้ใช้ต้องดำเนินการ (ฝั่งกล่อง Playbox)

### 1. เปิดกล่องและต่ออุปกรณ์ควบคุม
- เปิดเครื่อง **Playbox** ให้พร้อมใช้งาน
- ต่อสายภาพเข้า **จอแสดงผล** และต่อ **เมาส์ + คีย์บอร์ด** เข้าพอร์ต USB ของกล่องให้เรียบร้อย

### 2. เชื่อมต่อเครือข่ายวงเดียวกับคอมพิวเตอร์และจดเลข IP
- เข้าไปล็อกอิน **Wi-Fi** (หรือเสียบสาย **LAN**) ที่อยู่ใน **วงแลนเดียวกัน** กับคอมพิวเตอร์ที่รัน AI อยู่
- เข้าเมนู **Settings -> Network & Internet** (หรือคลิกที่ชื่อ Wi-Fi/LAN ที่เชื่อมต่ออยู่) แล้ว **จดเลข IP Address** ของกล่องไว้ (เช่น `192.168.1.105`)

### 3. เปิด Developer Options และ Debug Mode
ทำตามลำดับนี้บนหน้าจอกล่อง Playbox:
1. ไปที่ **Settings** (การตั้งค่า)
2. เข้าเมนู **Device Preferences** (ค่ากำหนดอุปกรณ์)
3. เข้าเมนู **About** (เกี่ยวกับ)
4. เลื่อนหาหัวข้อ **Build Number** (บิลด์ของระบบปฏิบัติการ) แล้ว **ดับเบิ้ลคลิก / คลิกซ้ำ 7 ครั้งติดกัน** จนขึ้นข้อความว่า *"You are now a developer!"* (คุณเป็นนักพัฒนาแล้ว)
5. กดย้อนกลับมาที่หน้า **Settings** -> เข้าเมนู **Developer options** (ตัวเลือกนักพัฒนาแอป)
6. เปิด/ตั้งค่าตัวเลือกต่อไปนี้:
   - ติ๊กเปิด **ADB debugging** / **USB debugging** (การแก้ไขข้อบกพร่อง USB)
   - ติ๊กเปิด **Internet ADB** / **Network debugging** *(ถ้ากล่องรุ่นนั้นมีเมนูนี้)*
   - เข้าหัวข้อ **เลือกการกำหนดค่า USB (Select USB Configuration)** -> เลือกเป็น **`MTP`** (Media Transfer Protocol)

### 4. แจ้งเลข IP ให้ AI เชื่อมต่อ ADB
- สั่งในแชทให้ AI เชื่อมต่อ ADB เข้าไปยังกล่อง พร้อมแจ้ง **เลข IP ที่จดไว้** และงานที่ต้องการทำ เช่น:
  - *"ADB เข้ากล่อง Playbox IP `192.168.1.105` หน่อย"*
  - *"เช็คข้อมูลเครื่อง เวอร์ชัน WebView และสถานะ DS Loader ของกล่อง `192.168.1.105`"*
  - *"ตั้ง Timezone เป็น `Asia/Bangkok` ให้กล่อง `192.168.1.105`"*

### 5. กดยืนยัน (Allow) ที่หน้าจอกล่อง Playbox (เฉพาะการเชื่อมต่อครั้งแรก — ยืนยันจากหน้างานจริงแล้ว)
- เมื่อ AI สั่ง `adb connect` เข้าไป **ครั้งแรกจากคอมพิวเตอร์เครื่องนั้น** กล่องจะขึ้นสถานะ `unauthorized` ชั่วคราว และระบบจะเด้งหน้าต่าง Pop-up **"Allow USB debugging?"** ขึ้นมาบนหน้าจอกล่อง Playbox ทันที
- **สิ่งที่ต้องทำบนหน้าจอ:**
  1. ใช้เมาส์หรือรีโมต **ติ๊กถูกที่ `Always allow from this computer`** (เพื่อให้ครั้งต่อไปเชื่อมต่อได้ทันทีโดยไม่ต้องกดย้ำ)
  2. กดปุ่ม **`Allow` (อนุญาต)** ฝั่ง Playbox
- เมื่อกดเสร็จแล้ว แจ้ง AI ในแชท AI จะเชื่อมต่อและดึงข้อมูลหรือตั้งค่าต่อได้ทันทีโดยไม่ต้องเริ่มใหม่

## ความสามารถที่ AI ทำให้ได้ผ่าน MCP Tool `playbox_adb`

| หมวดงาน | ตัวอย่างสิ่งที่สั่ง AI ได้ |
|---|---|
| **เชื่อมต่อ & ตรวจสภาพเครื่อง** | เชื่อมต่อ/ตัดการเชื่อมต่อ, ดูรุ่นเครื่อง, Android/SDK version, พื้นที่ `/data`, RAM, Timezone, เวลาเครื่อง, แคปหน้าจอกล่องลง `SANDBOX/` |
| **ตรวจแอป & ระบบ Target-R** | เช็คแอป `net.targetr.stacks.central` (DS Loader) ว่าติดตั้ง/รันอยู่หรือไม่, เช็ค `dumpsys webviewupdate`, เช็คสิทธิ์และบริการ Location/Wi-Fi Scan, ดึง `logcat` ล่าสุด, ค้นหารายชื่อแอปในเครื่อง |
| **ปรับตั้งค่า** | อ่าน/แก้ `settings` (`system`, `secure`, `global`), อ่าน/แก้ `getprop`/`setprop`, ตั้ง Timezone (`Asia/Bangkok`), มอบสิทธิ์แอป (`pm grant`) |
| **สั่งงานและควบคุม** | เปิด/ปิด/รีสตาร์ทแอป, ส่งปุ่มรีโมต (`HOME`, `BACK`, `DPAD`), เปิด URL, ติดตั้ง `.apk`, ล้างข้อมูลแอป, รีบูตเครื่อง *(คำสั่งเสี่ยงสูง AI จะขอคำยืนยันก่อนเสมอ)* |

## การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

| อาการ / สถานะ | สาเหตุที่เป็นไปได้ | วิธีแก้ไข |
|---|---|---|
| **`unauthorized`** | กล่องรอการกดอนุญาต RSA key จากคอมพิวเตอร์ | มองหา Pop-up บนหน้าจอกล่อง Playbox ติ๊ก *Always allow* แล้วกด **Allow / อนุญาต** จากนั้นให้ AI ลองใหม่ |
| **`unreachable` / `timeout`** | คนละวงแลน, IP ผิด, หรือยังไม่เปิด Network ADB | 1. ตรวจว่าคอมพ์และกล่องอยู่ Wi-Fi/LAN วงเดียวกัน<br/>2. เช็คเลข IP ในกล่องอีกครั้ง<br/>3. ตรวจว่าเปิด **ADB debugging + Internet ADB** และตั้ง USB Configuration เป็น **MTP** แล้ว (บางรุ่นต้องเสียบ/ถอดใหม่หรือเปิดปิด Developer Options อีกรอบ) |
| **ปิด Debug หลังจบงาน** | เมื่อหน้างานตั้งค่าเสร็จแล้ว | หากไม่ต้องการเปิดทิ้งไว้ในสาขา ให้ปิด **ADB debugging** ใน Developer options ก่อนถอดเมาส์/คีย์บอร์ด |
